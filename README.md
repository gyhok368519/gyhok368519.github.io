# 个人主页

我的作品集主页：一个静态页面，把我在用的几个投资工具收在一起，方便别人查看和使用。

线上地址：https://gyhok368519.github.io/

## 怎么改内容

**只需要改一个文件：`index.html`。**

页面里所有内容都由 `index.html` 底部的 `PROJECTS` 数组生成。新增一个作品，就在数组里加一段：

```js
{
  title: "作品名",
  desc:  "一句话说清楚它能干什么",
  tags:  ["标签1", "标签2"],
  url:   "https://线上地址",
  status: "live"        // live 已上线 / soon 待上线 / proto 原型
}
```

会出现的两种情况：

- `url` 填了地址 → 卡片可以点击，直接跳转过去
- `url` 留空 `""` → 卡片显示成灰色、不可点击，适合还没上线的作品

**顺序就是页面顺序**：想置顶谁，就把它往上挪。

改完保存，刷新浏览器就能看到效果。加完作品**不用手动改任何数字** —— 首屏「作品总数 / 已上线 / 待上线 / 原型演示」那四个统计，是按 `PROJECTS` 里各条 `status` 现算的。

### 页面结构：三栏

大屏（1024px 以上）是**三栏**：

| 位置 | 内容 | 怎么改 |
|---|---|---|
| 左栏 | 个人名片（照片 + 名字 + 一句话）+ 作品统计 | 照片见下一节；名字在 `.avatar-card` 里的 `<h1>` |
| 中栏 | 简介 + 正在做的事 + 作品卡片 | 改 `PROJECTS` 数组 |
| 右栏 | 联系我（邮箱 / 公众号）+ 站外链接 | 直接改右栏那两段 HTML |

中小屏会依次收成一栏：**先左右两栏掉到上面和下面，然后照片缩成小圆头像**（否则手机上一张大图会把内容全挤出屏幕）。

### 放你的照片

照片已经接上了（`avatar.jpg`），显示在左栏名片里。要换照片：

1. 新照片存到本文件夹，**覆盖** `avatar.jpg`（文件名保持一致就不用改代码）
2. 如果要用别的文件名，就在 `index.html` 里搜 `photo-frame`，把 `<img src="avatar.jpg" ...>` 的 `src` 改掉

照片框是正方形，照片会被自动裁切。当前用 `object-position: 50% 35%` 控制裁切位置——**想让脸更靠上就把 35% 调小，想更靠下就调大**：

```css
.photo-frame img{object-fit:cover;object-position:50% 35%}
```

手机上照片会自动缩成 64px 圆头像，不占版面。

## 怎么发布到 GitHub Pages

### 第一次发布

1. 登录 GitHub，点右上角 **+** → **New repository**
2. 仓库名必须填 `gyhok368519.github.io`（一字不差，这是 GitHub 的固定规则，用这个仓库名才能得到 `https://gyhok368519.github.io` 这个地址）
3. 可见性选 **Public**，不要勾选 "Add a README file"
4. 点 **Create repository**
5. 在本文件夹里打开命令行，依次执行：

```bash
git init
git add .
git commit -m "个人主页第一版"
git branch -M main
git remote add origin https://github.com/gyhok368519/gyhok368519.github.io.git
git push -u origin main
```

推送时如果要求输入密码，要填 **Personal Access Token**（不是 GitHub 登录密码）。

6. 等 1-2 分钟，打开 https://gyhok368519.github.io/ 就能看到页面

### 以后更新

改完 `index.html` 之后：

```bash
git add .
git commit -m "更新内容"
git push
```

等一分钟，线上自动更新。

## 设计规范（改样式时对照）

- **配色**：白/浅灰底 + 近黑文字 + 单一蓝色强调（`--brand: #1a73e8`）。全站只有一条彩色，靠灰色阶拉开层次，不引入第二种彩色。
- **字体**：只用系统字体栈，零外部加载；靠字号 + 字重拉层级，不混用第二款字体。
- **断点**：从 320px 起步，**移动优先**，只向上增强 —— 576px（名片横排 + 统计 4 列）、768px（卡片 2 列、页脚两端对齐）、1024px（三栏 + 左右栏跟随滚动）。卡片用 `repeat(auto-fit, minmax(240px, 1fr))`，加作品不用改布局。
- **三栏为何定在 1024px**：左栏 210 + 右栏 240 + 左右间距 60 是固定的，中栏低于约 420px 卡片就会挤成单列。所以断点必须落在能同时容下三栏的地方，否则内容比单栏时还窄。
- **无障碍**：正文对比度不低于 4.5:1（实测最低 5.62）、键盘 Tab 焦点环可见、状态不只靠颜色区分（"已上线"实底胶囊 / "待上线"描边空心胶囊，形状也不同）。

## 背景装饰与动画

### 背景

`.bg-decor` 是固定铺满视口的装饰层（`z-index:-1`、`pointer-events:none`、`aria-hidden`），里面两层：

1. **细网格** —— 用 1px 线性重复渐变画的，没有图片、没有外部请求，离线照样显示
2. **两束柔光** —— 模糊圆形光斑，26 秒 / 32 秒缓慢反向漂移

**它们刻意压在极低对比度**（网格约 5% 透明度）。这不是省事，是因为背景一浓就会拉低文字对比度——那会直接违反无障碍要求。所以它只做氛围，不承载任何信息。

改颜色：顶部 `:root` 里的 `--grid-line` / `--glow-a` / `--glow-b`；暗色模式在 `prefers-color-scheme: dark` 里对应改。

### 动画清单

| 效果 | 做法 |
|---|---|
| 内容逐块入场 | 滚进视口时淡入 + 上移 14px，用 `IntersectionObserver` 触发 |
| 卡片错开浮现 | 每张卡延迟 70ms，形成节奏 |
| 悬停微光 | 卡片上一道斜向高光扫过 |
| 照片柔光 | 照片框上缓慢明暗呼吸 |
| 背景视差 | 鼠标移动时两束光反向轻微偏移 |
| 卡片 3D 倾斜 | 指针位置决定卡片绕轴旋转角（最大 5°）并上浮 3px |

### 关节动效时的两条硬规则

**一、系统开了「减弱动效」就全部关掉。** 代码里先判断 `prefers-reduced-motion`，命中就**连事件监听都不注册**，同时 CSS 里也有一层 `@media` 兜底。这是无障碍要求，不是可选项。

**二、入场位移用 `translate` 属性，不用 `transform`。** 因为卡片的 3D 倾斜也占用 `transform`。早期版本里 `.reveal.in{transform:none}` 的优先级高于 `a.card`，**把倾斜的 transform 整个干掉了**——变量算得对、规则也匹配，但卡片就是不转。改用独立的 `translate` 属性后两者才能共存。

同理，`3D 倾斜`里旋转角必须在 JS 里算好带单位写进变量（`--rx: 4.8deg`），**不能写成 `calc(var(--mx) * 5deg)`**——未注册的自定义属性按字符串替换处理，那样写 `transform` 会整条失效。

## 为什么要保持单文件

整站只有一个 `index.html`，没有外部依赖、没有构建步骤。好处是：

- 任何地方双击就能打开，不需要装环境
- 想搬到别的平台（Cloudflare Pages、Vercel 等）直接拷过去就行
- 以后要绑定自己的域名，也不用改任何代码
